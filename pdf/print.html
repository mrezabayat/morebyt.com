C++ Roadmap 2027

What to learn, in order. Tick a box when you can do it without a tutorial.

42 steps · 10–14 monthsat ~10 hours a week
+ DSA practice from stage 3
  • C++17 Most job code
  • C++20 Your default
  • C++23 Where your compiler has it
  • C++26 Not a standard yet
01Tools and core language4–6 weeks
  • Compile with C++20 and all warnings on — zero warnings
  • Use references, const, string, vector, struct, enum class
  • Split code into headers and sources; explain what the linker does
  • Step through a crash in a debugger; read the call stack
  • Commit daily; push to GitHub with a README
02Memory, lifetime and RAII6–8 weeks
  • Explain stack vs heap, pointer vs reference
  • Apply RAII and the Rule of Zero/Five
  • Explain std::move (it's only a cast)
  • unique_ptr by default; know what shared_ptr costs
  • Every debug build runs AddressSanitizer + UBSan
  • Build your own Vector<T>, sanitizer-clean
  • Draw who owns what before you code
03Standard library and modern C++6–8 weeks
  • Choose the right container; know iterator invalidation
  • Use algorithms and lambdas instead of raw loops
  • Write a template constrained with a concept
  • Use optional, variant, span, string_view, expected
  • 2–3 DSA problems a week in clean C++
04A project a stranger can build3–4 weeks
  • Target-based CMake; one-command build
  • One dependency through vcpkg or Conan
  • Unit tests with GoogleTest or Catch2
  • clang-format, clang-tidy, standard-library hardening on
  • CI: build + tests + sanitizers on every push
  • AGENTS.md with the build, test and sanitizer gate
05How the machine works6–8 weeks
  • Explain caches, cache lines, alignment and padding
  • Read simple assembly on Compiler Explorer
  • Explain processes, threads, virtual memory, system calls
  • Write a TCP server with sockets
  • Profile, benchmark and publish a write-up
06Concurrency5–6 weeks
  • Use threads, mutexes, condition variables, atomics correctly
  • Explain data race vs race condition, deadlock, false sharing
  • A thread pool + queue that's clean under ThreadSanitizer
07Reading other people's code4–6 weeks
  • Build an open-source C++ project from source
  • Get one meaningful pull request merged
08Specialise and get hired8–12 weeks
  • Pick one industry and learn its extra skills
  • Enough Python for build scripts and test tools
  • One flagship project with benchmarks and a write-up
  • ~150 DSA problems in clean C++
  • 10 interview questions out loud + one design problem in 45 min
  • One-page CV with numbers; 2–4 repos that build
  • Apply by job title; ask engineers for referrals
  • Write a one-page DESIGN.md before the flagship
  • Find a lifetime or design bug in an AI-written PR
Every projectBuilds in one command, has tests, sanitizers in CI, one measured number.
Pick one laneEmbedded, robotics, infrastructure, AI runtimes, simulation — not five.
